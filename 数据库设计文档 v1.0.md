## 1. 用户系统

### 1.1 users（用户表）

**用途**：存储用户基本信息和学习偏好

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | UUID | PRIMARY KEY | 用户唯一标识，关联 auth.users |
| auth_id | UUID | REFERENCES auth.users(id) | Supabase Auth 用户ID |
| name | TEXT | | 用户姓名 |
| age | INTEGER | | 年龄 |
| interests | TEXT[] | | 兴趣标签数组，如 ['数学', '编程', '科学'] |
| grade | TEXT | | 年级，如 '小学三年级', '初中一年级' |
| avatar_url | TEXT | | 用户头像URL |
| created_at | TIMESTAMP | DEFAULT NOW() | 创建时间 |
| updated_at | TIMESTAMP | DEFAULT NOW() | 更新时间 |

```sql
CREATE TABLE users (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  auth_id UUID REFERENCES auth.users(id) UNIQUE,
  name TEXT,
  age INTEGER,
  interests TEXT[],
  grade TEXT,
  avatar_url TEXT,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);
```

---

### 1.2 user_profile（用户画像表）

**用途**：存储长期记忆和用户学习行为关键信息

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | UUID | PRIMARY KEY | 记录唯一标识 |
| user_id | UUID | REFERENCES users(id) | 关联用户 |
| key | TEXT | NOT NULL | 记忆键，如 'favorite_subject', 'recent_struggle', 'learning_style' |
| value | TEXT | NOT NULL | 记忆值，JSON格式或文本 |
| importance | INTEGER | CHECK (1-10) | 重要性评分 1-10 |
| last_mentioned | TIMESTAMP | | 最后提及时间 |
| created_at | TIMESTAMP | DEFAULT NOW() | 创建时间 |

**索引**：
```sql
CREATE INDEX idx_profile_user ON user_profile(user_id);
CREATE INDEX idx_profile_key ON user_profile(user_id, key);
```

**示例数据**：
```sql
INSERT INTO user_profile (user_id, key, value, importance) VALUES
('user-123', 'favorite_subject', '数学', 8),
('user-123', 'recent_struggle', '分数运算', 9),
('user-123', 'learning_style', '喜欢通过图形理解概念', 7);
```

## 2. 对话系统

### 2.1 conversations（对话会话表）

**用途**：管理用户与AI角色的对话会话

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | UUID | PRIMARY KEY | 会话唯一标识 |
| user_id | UUID | REFERENCES users(id) | 关联用户 |
| character_id | UUID | REFERENCES characters(id) | 关联角色（小鳄鱼/极客狐狸等） |
| title | TEXT | | 会话标题，如 '数学作业帮助' |
| summary | TEXT | | 会话摘要（可选） |
| is_active | BOOLEAN | DEFAULT TRUE | 是否活跃 |
| ended_at | TIMESTAMP | | 会话结束时间 |
| created_at | TIMESTAMP | DEFAULT NOW() | 创建时间 |
| updated_at | TIMESTAMP | DEFAULT NOW() | 最后更新时间 |

```sql
CREATE TABLE conversations (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id UUID REFERENCES users(id) ON DELETE CASCADE,
  character_id UUID REFERENCES characters(id),
  title TEXT,
  summary TEXT,
  is_active BOOLEAN DEFAULT TRUE,
  ended_at TIMESTAMP,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);
```

---

### 2.2 messages（消息表）

**用途**：存储对话中的每条消息

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | UUID | PRIMARY KEY | 消息唯一标识 |
| conversation_id | UUID | REFERENCES conversations(id) | 关联会话 |
| user_id | UUID | REFERENCES users(id) | 关联用户 |
| character_id | UUID | REFERENCES characters(id) | 关联角色 |
| role | TEXT | NOT NULL | 'user' 或 'assistant' |
| content | TEXT | NOT NULL | 消息内容 |
| intent_type | TEXT | | 意图类型：'homework', 'knowledge', 'chat', 'emotional' |
| mode | TEXT | | 教学模式：'socratic', 'normal', 'encourage' |
| metadata | JSONB | | 额外元数据（如情绪分析结果） |
| tokens_used | INTEGER | | 消耗的token数 |
| created_at | TIMESTAMP | DEFAULT NOW() | 创建时间 |

```sql
CREATE TABLE messages (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  conversation_id UUID REFERENCES conversations(id) ON DELETE CASCADE,
  user_id UUID REFERENCES users(id) ON DELETE CASCADE,
  character_id UUID REFERENCES characters(id),
  role TEXT NOT NULL CHECK (role IN ('user', 'assistant')),
  content TEXT NOT NULL,
  intent_type TEXT CHECK (intent_type IN ('homework', 'knowledge', 'chat', 'emotional')),
  mode TEXT CHECK (mode IN ('socratic', 'normal', 'encourage')),
  metadata JSONB,
  tokens_used INTEGER,
  created_at TIMESTAMP DEFAULT NOW()
);
```

**索引**：
```sql
CREATE INDEX idx_messages_conversation ON messages(conversation_id);
CREATE INDEX idx_messages_user ON messages(user_id);
CREATE INDEX idx_messages_created ON messages(created_at DESC);
```

## 3. 角色系统

### 3.1 characters（对话角色表）

**用途**：存储AI角色配置（小鳄鱼、极客狐狸等）

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | UUID | PRIMARY KEY | 角色唯一标识 |
| name | TEXT | NOT NULL | 角色名称，如 '小鳄鱼', '极客狐狸' |
| slug | TEXT | UNIQUE NOT NULL | URL友好标识，如 'little-croc' |
| avatar_url | TEXT | | 角色头像URL |
| description | TEXT | | 角色简介 |
| personality | TEXT | | 性格描述 |
| system_prompt | TEXT | NOT NULL | Claude 系统提示词 |
| tone | TEXT | | 语气风格：'可爱', '专业', '幽默' |
| expertise | TEXT[] | | 擅长领域数组 |
| target_age_group | TEXT[] | | 目标年龄组：['小学', '初中'] |
| model | TEXT | DEFAULT 'claude-sonnet-4-20250514' | 使用的AI模型 |
| temperature | FLOAT | DEFAULT 0.7 | 温度参数 0.0-1.0 |
| max_tokens | INTEGER | DEFAULT 1000 | 最大token数 |
| is_active | BOOLEAN | DEFAULT TRUE | 是否启用 |
| is_premium | BOOLEAN | DEFAULT FALSE | 是否付费角色 |
| sort_order | INTEGER | DEFAULT 0 | 显示排序 |
| created_at | TIMESTAMP | DEFAULT NOW() | 创建时间 |
| updated_at | TIMESTAMP | DEFAULT NOW() | 更新时间 |

```sql
CREATE TABLE characters (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  name TEXT NOT NULL,
  slug TEXT UNIQUE NOT NULL,
  avatar_url TEXT,
  description TEXT,
  personality TEXT,
  system_prompt TEXT NOT NULL,
  tone TEXT,
  expertise TEXT[],
  target_age_group TEXT[],
  model TEXT DEFAULT 'claude-sonnet-4-20250514',
  temperature FLOAT DEFAULT 0.7 CHECK (temperature >= 0 AND temperature <= 1),
  max_tokens INTEGER DEFAULT 1000,
  is_active BOOLEAN DEFAULT TRUE,
  is_premium BOOLEAN DEFAULT FALSE,
  sort_order INTEGER DEFAULT 0,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);
```

**索引**：
```sql
CREATE INDEX idx_characters_active ON characters(is_active, sort_order);
CREATE INDEX idx_characters_slug ON characters(slug);
```

## 6. Row Level Security (RLS)

### 6.1 用户表 RLS

```sql
-- 启用 RLS
ALTER TABLE users ENABLE ROW LEVEL SECURITY;

-- 用户只能查看和修改自己的信息
CREATE POLICY "Users can view own profile"
ON users FOR SELECT
USING (auth.uid() = auth_id);

CREATE POLICY "Users can update own profile"
ON users FOR UPDATE
USING (auth.uid() = auth_id);
```

### 6.2 对话表 RLS

```sql
ALTER TABLE conversations ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Users can view own conversations"
ON conversations FOR SELECT
USING (auth.uid() = (SELECT auth_id FROM users WHERE id = user_id));

CREATE POLICY "Users can create own conversations"
ON conversations FOR INSERT
WITH CHECK (auth.uid() = (SELECT auth_id FROM users WHERE id = user_id));
```

### 6.3 消息表 RLS

```sql
ALTER TABLE messages ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Users can view own messages"
ON messages FOR SELECT
USING (auth.uid() = (SELECT auth_id FROM users WHERE id = user_id));

CREATE POLICY "Users can insert own messages"
ON messages FOR INSERT
WITH CHECK (auth.uid() = (SELECT auth_id FROM users WHERE id = user_id));
```

### 6.4 播客推送 RLS

```sql
ALTER TABLE user_podcast_feeds ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Users can view own podcast feeds"

## 7. 数据库触发器

### 7.1 自动同步 auth.users 到 users 表

```sql
CREATE OR REPLACE FUNCTION public.handle_new_user()
RETURNS TRIGGER AS $$
BEGIN
  INSERT INTO public.users (id, auth_id, name, avatar_url)
  VALUES (
    NEW.id,
    NEW.id,
    COALESCE(NEW.raw_user_meta_data->>'name', 'User'),
    NEW.raw_user_meta_data->>'avatar_url'
  );
  RETURN NEW;
END;
$$ LANGUAGE plpgsql SECURITY DEFINER;

CREATE TRIGGER on_auth_user_created
  AFTER INSERT ON auth.users
  FOR EACH ROW EXECUTE FUNCTION public.handle_new_user();
```

### 7.2 自动更新 updated_at 字段

```sql
CREATE OR REPLACE FUNCTION update_updated_at_column()
RETURNS TRIGGER AS $$
BEGIN
  NEW.updated_at = NOW();
  RETURN NEW;
END;
$$ LANGUAGE plpgsql;

-- 应用到各表
CREATE TRIGGER update_users_updated_at
  BEFORE UPDATE ON users
  FOR EACH ROW EXECUTE FUNCTION update_updated_at_column();

CREATE TRIGGER update_conversations_updated_at
  BEFORE UPDATE ON conversations
  FOR EACH ROW EXECUTE FUNCTION update_updated_at_column();

CREATE TRIGGER update_characters_updated_at
  BEFORE UPDATE ON characters
  FOR EACH ROW EXECUTE FUNCTION update_updated_at_column();
```

### 7.3 自动创建默认播客偏好

```sql
CREATE OR REPLACE FUNCTION create_default_podcast_preference()
RETURNS TRIGGER AS $$
BEGIN
  INSERT INTO user_podcast_preferences (user_id, preferred_tags)
  VALUES (NEW.id, NEW.interests);
  RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER on_user_created_podcast_pref
  AFTER INSERT ON users
  FOR EACH ROW EXECUTE FUNCTION create_default_podcast_preference();
```

## 8. ER 图

### 8.1 实体关系概览

```
┌─────────────┐
│ auth.users  │
│ (Supabase)  │
└──────┬──────┘
       │ 1:1
       ▼
┌─────────────┐         ┌──────────────────┐
│   users     │────────▶│  user_profile    │
│             │ 1:N     │  (长期记忆)       │
└──────┬──────┘         └──────────────────┘
       │ 1:N
       ▼
┌─────────────────┐     ┌──────────────────┐
│ conversations   │────▶│  messages        │
│                 │ 1:N │                  │
└────────┬────────┘     └──────────────────┘
         │
         │ N:1
         ▼
┌─────────────────┐     ┌──────────────────────────┐
│  characters     │────▶│ character_user_memories  │
│ (角色配置)       │ 1:N │ (角色记忆)                │
└─────────────────┘     └──────────────────────────┘

┌─────────────┐         ┌──────────────────────┐
│   podcasts  │────────▶│ user_podcast_feeds   │
│             │ 1:N     │                      │
└─────────────┘         └──────────────────────┘
                                 ▲
                                 │ N:1
                        ┌────────┴────────┐
                        │ user_podcast_   │
                        │  preferences    │
                        └─────────────────┘
```

### 8.2 关系说明

| 关系 | 类型 | 说明 |
|------|------|------|
| users ↔ user_profile | 1:N | 一个用户有多条画像记录 |
| users ↔ conversations | 1:N | 一个用户有多个对话 |
| conversations ↔ messages | 1:N | 一个对话有多条消息 |
| characters ↔ conversations | 1:N | 一个角色参与多个对话 |
| users ↔ user_podcast_feeds | 1:N | 一个用户接收多条播客 |
| podcasts ↔ user_podcast_feeds | 1:N | 一条播客推送给多个用户 |

## 9. 初始化脚本

### 9.1 完整建表脚本

```sql
-- =============================================
-- 教育AI助手数据库初始化脚本
-- Version: 1.0
-- Date: 2025-01-05
-- =============================================

-- 启用 UUID 扩展
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";

-- ============ 1. 用户系统 ============

CREATE TABLE users (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  auth_id UUID REFERENCES auth.users(id) UNIQUE,
  name TEXT,
  age INTEGER,
  interests TEXT[],
  grade TEXT,
  avatar_url TEXT,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE user_profile (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id UUID REFERENCES users(id) ON DELETE CASCADE,
  key TEXT NOT NULL,
  value TEXT NOT NULL,
  importance INTEGER CHECK (importance BETWEEN 1 AND 10),
  last_mentioned TIMESTAMP,
  created_at TIMESTAMP DEFAULT NOW()
);

-- ============ 2. 角色系统 ============

CREATE TABLE characters (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  name TEXT NOT NULL,
  slug TEXT UNIQUE NOT NULL,
  avatar_url TEXT,
  description TEXT,
  personality TEXT,
  system_prompt TEXT NOT NULL,
  tone TEXT,
  expertise TEXT[],
  target_age_group TEXT[],
  model TEXT DEFAULT 'claude-sonnet-4-20250514',
  temperature FLOAT DEFAULT 0.7 CHECK (temperature >= 0 AND temperature <= 1),
  max_tokens INTEGER DEFAULT 1000,
  is_active BOOLEAN DEFAULT TRUE,
  is_premium BOOLEAN DEFAULT FALSE,
  sort_order INTEGER DEFAULT 0,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE character_user_memories (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  character_id UUID REFERENCES characters(id) ON DELETE CASCADE,
  user_id UUID REFERENCES users(id) ON DELETE CASCADE,
  memory_key TEXT NOT NULL,
  memory_value TEXT NOT NULL,
  importance INTEGER CHECK (importance BETWEEN 1 AND 10),
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW(),
  UNIQUE(character_id, user_id, memory_key)
);

-- ============ 3. 对话系统 ============

CREATE TABLE conversations (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id UUID REFERENCES users(id) ON DELETE CASCADE,
  character_id UUID REFERENCES characters(id),
  title TEXT,
  summary TEXT,
  is_active BOOLEAN DEFAULT TRUE,
  ended_at TIMESTAMP,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE messages (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  conversation_id UUID REFERENCES conversations(id) ON DELETE CASCADE,
  user_id UUID REFERENCES users(id) ON DELETE CASCADE,
  character_id UUID REFERENCES characters(id),
  role TEXT NOT NULL CHECK (role IN ('user', 'assistant')),
  content TEXT NOT NULL,
  intent_type TEXT CHECK (intent_type IN ('homework', 'knowledge', 'chat', 'emotional')),
  mode TEXT CHECK (mode IN ('socratic', 'normal', 'encourage')),
  metadata JSONB,
  tokens_used INTEGER,
  created_at TIMESTAMP DEFAULT NOW()
);

-- ============ 4. 播客系统 ============

CREATE TABLE podcasts (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  title TEXT NOT NULL,
  content TEXT,
  audio_url TEXT,
  summary TEXT,
  tags TEXT[],
  target_grades TEXT[],
  source_url TEXT,
  duration_seconds INTEGER,
  publish_date DATE DEFAULT CURRENT_DATE,
  is_published BOOLEAN DEFAULT FALSE,
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE user_podcast_feeds (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id UUID REFERENCES users(id) ON DELETE CASCADE,
  podcast_id UUID REFERENCES podcasts(id) ON DELETE CASCADE,
  is_read BOOLEAN DEFAULT FALSE,
  rating INTEGER CHECK (rating BETWEEN 1 AND 5),
  feedback TEXT,
  pushed_at TIMESTAMP DEFAULT NOW(),
  read_at TIMESTAMP,
  UNIQUE(user_id, podcast_id)
);

CREATE TABLE user_podcast_preferences (
  user_id UUID PRIMARY KEY REFERENCES users(id) ON DELETE CASCADE,
  preferred_tags TEXT[],
  push_time TIME DEFAULT '08:00:00',
  is_enabled BOOLEAN DEFAULT TRUE,
  frequency TEXT DEFAULT 'daily' CHECK (frequency IN ('daily', 'weekly', 'custom')),
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

ALTER TABLE conversations ENABLE ROW LEVEL SECURITY;

  USING (auth.uid() = (SELECT auth_id FROM users WHERE id = user_id));
CREATE POLICY "Users can create conversations" ON conversations FOR INSERT
